# Task 3: Data Cleaning

## Objective
Demonstrate professional-level data cleaning skills by taking a messy dataset and systematically transforming it into a clean, analysis-ready format.

## Tech Stack
- Python
- Pandas
- NumPy
- Google Colab / Jupyter Notebook

## Key Steps Executed
1. **Data Inspection & Quality Report:** Loaded the dataset, inspected shape, checked for missing values, duplicate rows, and data types.
2. **Handling Missing Values:** Imputed numerical missing values using the median and categorical missing values using the mode.
3. **Duplicate Removal:** Identified and dropped duplicate rows to ensure data integrity.
4. **Outlier Treatment:** Detected outliers in numerical columns using the Interquartile Range (IQR) method and applied capping.
5. **Exporting Clean Data:** Exported the processed and standardized dataset to `cleaned_dataset.csv`.
